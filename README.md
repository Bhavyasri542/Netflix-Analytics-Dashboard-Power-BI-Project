# Netflix-Analytics-Dashboard-Power-BI-Project
Developed an interactive Netflix Analytics Dashboard in Power BI to analyze and visualize Netflix content data. The dashboard provides insights into content types, ratings, genres, release trends, and country-wise distribution using dynamic charts, KPIs, and filters for better decision-making and data exploration.
🎬 Netflix Analytics Dashboard

📌 Project Overview

📊 Developed an interactive Netflix Analytics Dashboard using Power BI.

🎥 Analyzed Netflix Movies and TV Shows data to discover content trends and patterns.

🌍 Explored content distribution across countries, genres, ratings, and release years.

📈 Created visualizations to help users gain meaningful insights from Netflix's content library.

🎯 Enabled data-driven analysis through interactive reports and filters.


🛠️ Tools Used

💻 Microsoft Power BI

📄 CSV Dataset (Netflix Titles Data)

🔄 Power Query Editor

📊 DAX (Data Analysis Expressions)

🗂️ Data Modeling

📈 Power BI Visualizations


✨ Dashboard Features

🌍 Country-wise Content Distribution

🎭 Genre-wise Content Analysis

📅 Release Year Trend Analysis

🍩 Interactive Donut and Pie Charts
